# Ruya — Handmade Gift Hampers & Clay Charms

A single-page site for Ruya, a handmade gift hampers and clay charms shop.

## What's inside
- `index.html` — the full site (shop, about, checkout with cart + WhatsApp ordering, all in one file, no build step needed)

## Running it locally
Just open `index.html` in any browser — no server or install required.

## Hosting it for free with GitHub Pages
1. Push this repo to GitHub (see steps below).
2. On the repo page, go to **Settings → Pages**.
3. Under "Build and deployment", set **Source** to `Deploy from a branch`.
4. Set the branch to `main` and folder to `/ (root)`, then **Save**.
5. GitHub will give you a live link, usually `https://<your-username>.github.io/ruya-test-website/`, within a minute or two.

## Before going live
- In `index.html`, search for `92XXXXXXXXXX` and replace it with your real WhatsApp number (digits only, country code first, no `+` or spaces).
- Update the placeholder bank/JazzCash/Easypaisa details in the checkout section.
- Swap in your real product photos, prices, and contact details.
